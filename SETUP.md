# Setup

## Requirements

- Windows 10/11 (uses `winsound` and Windows Startup/Start Menu folders —
  won't run as-is on macOS/Linux).
- Python 3.10+ (built and tested on 3.12).
- A Google account with a calendar you want alerts from.

This repo includes a `.python-version` file pinning `3.12.10` — that's only
used by [pyenv](https://github.com/pyenv/pyenv) / [pyenv-win](https://github.com/pyenv-win/pyenv-win),
and only if you already have it installed. If you don't use pyenv, ignore
that file — just make sure whatever `python`/`pip` you normally use is 3.10+.
If you do use pyenv-win but don't have 3.12.10 installed, either run
`pyenv install 3.12.10` or edit/delete `.python-version` to match a version
you already have.

## 1. Create Google OAuth credentials (one-time, do this yourself in your browser)

1. Go to https://console.cloud.google.com/ and create a new project (or pick
   an existing one you're fine using for this).
2. Go to **APIs & Services > Library**, search for **Google Calendar API**,
   and click **Enable**.
3. Go to **APIs & Services > OAuth consent screen**.
   - User type: **External** is fine for personal use.
   - Fill in an app name (e.g. "Meeting Notifier") and your email where
     required. You don't need to submit for verification — it can stay in
     "Testing" mode.
   - Under "Test users", add your own Google account email.
4. Go to **APIs & Services > Credentials > Create Credentials > OAuth client
   ID**.
   - Application type: **Desktop app**.
   - Name it anything, e.g. "Meeting Notifier Desktop".
5. Click **Download JSON** on the created client, rename the downloaded file
   to `credentials.json`, and place it directly in this `meeting_notifyer/`
   folder (next to `main.py`).

Each person running this needs a `credentials.json`. Either do the steps
above yourself, or if a teammate already created a project, ask them to add
your Google account under "Test users" on their OAuth consent screen and
share their `credentials.json` with you — either way works, since each
person still signs in with their own account and gets their own token.

## 2. Install dependencies

```
pip install -r requirements.txt
```

Run this from inside `meeting_notifyer/`.

## 3. First run (completes the OAuth login)

```
python main.py
```

A browser window will open asking you to sign in and grant read-only
calendar access. After approving, a `token.json` file is created
automatically and the tray icon should appear (look in the system tray
overflow arrow near the clock). Leave it running to confirm it works, then
close it (right-click tray icon > Quit) before setting up autostart.

## 4. Enable autostart + a searchable Start Menu entry

```
python install_autostart.py
```

This does two things:
- Drops a small launcher into your Windows Startup folder so the app starts
  automatically (no console window) whenever you log in.
- Creates a real Start Menu shortcut ("Meeting Notifier") with an icon, so
  you can press the Windows key, type "Meeting Notifier", and press
  Enter/click to launch it — same as any installed app, no command line
  needed.

Safe to re-run any time (e.g. after moving the folder). To remove both:
`python install_autostart.py --uninstall`.

### Restarting after you Quit from the tray

Quitting from the tray only stops that running instance — it doesn't relaunch
it. To start it again immediately: search "Meeting Notifier" in the Start
menu and click it (works once you've run step 4 above). It will otherwise
only restart automatically the next time you log into Windows.

## Day-to-day usage

Right-click (or click, for the default action) the tray icon for:
- **Open dashboard** — a window showing your upcoming meetings with live
  countdowns, a green/amber/red sync status dot, a "Sync now" button, and a
  "Preview alert" button that pops the full-screen alert on demand so you can
  check it looks right without waiting for a real meeting.
- **Sync now** — force an immediate calendar refresh.
- **Quit** — stops the running instance (see above for restarting).

## Notes

- `credentials.json` and `token.json` contain access to your calendar (read
  only) — don't share them or commit them to git (already in `.gitignore`).
- Settings like alert lead time (`alert_lead_seconds`) and sync frequency
  (`sync_interval_seconds`) live in `config.json` — edit and restart the app
  to apply changes.
- Logs are written to `notifier.log` in this folder if something isn't
  working as expected. It rotates every 24h and keeps 1 backup
  (`notifier.log.<date>`), so nothing older than ~48h is ever kept.
- `icon.ico` is auto-generated by `install_autostart.py` for the Start Menu
  shortcut — safe to delete, it's regenerated on the next install run
  (already in `.gitignore`).
